【布丁狗美化 · 没心机版】使用说明（meixinji 没心机小手机）
作者：淅沥沥 ｜ 仅保留「没心机」一份美化（小心机已按需求丢弃）

一、这个文件是什么
  - 没心机布丁狗.css：聊天界面 CSS 美化（奶黄/拿铁棕气泡、布丁狗挂件、
    甜点红包卡、趴趴狗挂件）。它是"界面外观"，不是角色人设。

二、怎么用
  1. 打开部署好的 meixinji 网页（xxx.pages.dev）
  2. 进入 设置 / 自定义样式（CSS）输入框
  3. 用任意文本编辑器打开 没心机布丁狗.css，全选复制全部内容
  4. 粘贴进输入框，保存/应用即可

三、配套（美化只是外观，聊天还需要）
  1. 设置里填 DeepSeek：
     接口 https://api.deepseek.com/v1/chat/completions
     模型 deepseek-chat
     填入你自己的 API Key
  2. 新建角色，写你的恋人向人设 prompt
  3. 开启主动消息，间隔建议 40 分钟~2 小时随机

四、注意事项
  - 布丁狗配图为网络图片（imagehub），需联网显示；离线时挂件图片会消失，
    颜色/样式仍保留。
  - 本美化仅供个人私下使用，禁止二传（作者要求）。
